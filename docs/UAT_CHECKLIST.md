# AI模拟面试平台 — 用户验收测试 (UAT) 任务表

> 版本: v1.0
> 更新日期: 2026-07-02
> 适用环境: 测试环境 / 预发布环境

---

## 使用说明

1. 每条任务按优先级分为 **P0(阻塞)** / **P1(重要)** / **P2(建议)**
2. 测试人员在「结果」列勾选 ✅通过 / ❌失败 / ⏭️跳过
3. 失败项在「备注」中记录复现步骤和截图
4. 全部 P0 通过后方可发布上线
