# Pathway Frontend Module (Isolated)

This module is intentionally not wired into router/navigation yet.

## Files
- `views/PathwayHomeView.vue`: standalone page scaffold
- `components/PathwayTaskList.vue`: task rendering block
- `api.ts`: pathway API wrapper
- `types.ts`: pathway type contracts

## Purpose
- Start implementation without affecting existing pages.
- Enable phased integration later behind a feature toggle.
